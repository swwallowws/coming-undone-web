# Coming Undone

simply split. Built copy; code lives elsewhere.

Split a song into parts and turn each one into MIDI:
https://swwallowws.github.io/coming-undone-web/

This repository holds only the built site. It runs a song online (a Hugging Face
Space), on your own computer, or entirely in your browser, where nothing is
uploaded. The guided demo is at /try/.
